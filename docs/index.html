discordjs-components-v2

Сборщик, разборщик и утилиты редактирования для Discord Components V2 — без кэшей состояния. Забрал → разобрал → поправил → отправил.

$ npm i discordjs-components-v2
Начать работу Смотрим пагинацию GitHub

Ключевая идея

Компоненты — это обычный JSON. Когда Discord отдаёт вам сообщение, он возвращает полное дерево компонентов в message.components. Значит, состояние сообщения не нужно хранить у себя: в любой момент его можно заново составить, изменить и отправить обратно. Это и есть принцип «без кэшей», на котором построена вся библиотека.

ts
const message = await ctx.fetchReply();

const builder = V2Builder.parse(message);   // raw JSON → билдер
builder
  .replaceText("0 участников", "1 участник")
  .setButtonLabel("join", "Розыгрыш закрыт")
  .disableButtons();

await builder.send(ctx);                    // editReply внутри

Работает на чистых структурах discord-api-types/v10. discord.js не нужен в рантайме и как peer-зависимость — результат полностью совместим с discord.js v14: передавайте JSON прямо в components:.

Возможности

🧱

V2Builder

Декларативная сборка: текст, кнопки, селекты, секции, разделители, галереи, вложения и ANSI-таблицы.

♻️

Кэш-фри разбор

parseComponents() / V2Builder.parse() превращают message.components обратно в билдер.

✂️

Утилиты редактирования

editComponents() / ComponentsEditor: удалить, заменить, переместить, отключить кнопки, переписать текст.

📝

Модальные окна V2

V2ModalBuilder: плоские описания полей, типизированный разбор сабмита (parseSubmit), валидация и rule().

🆔

Состояние в customId

CustomIdBuilder — кодек name:entityId:executorId с гарантией ≤ 100 символов.

🛡️

Валидация

validateComponents() / build() ловят лимиты Discord до отправки.

🧩

Шаблоны и пагинация

V2Template — слоты и сентинелы; V2Paginator — бесстейтовые страницы без кэша.
