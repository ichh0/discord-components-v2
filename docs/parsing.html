Parser

Разбор без кэша

Главная фича: `fetch → parse → edit → send` без хранения состояния.

Discord возвращает полное дерево компонентов в message.components. Библиотека умеет превратить его обратно в живой V2Builder — поэтому состояние сообщения можно никогда не хранить у себя:

ts
// где-то потом, хоть через неделю:
const message = await interaction.fetchReply();

const builder = parseComponents(message);  // raw JSON → билдер

builder
  .replaceText("0 участников", "1 участник")
  .setButtonLabel("join", "Розыгрыш закрыт")
  .disableButtons();                       // выключить все, включая аксессуары секций

await builder.send(interaction);           // editReply внутри

parseComponents(x) — это то же самое, что V2Builder.parse(x).

Что можно скормить парсеру

ВходПример
Массив сырых компонентов[...message.components]
Message-like объект{ components: [...], content } — fetched Message тоже ок
Одиночный компонент{ type: 17, components: [...] }
Что угодно с .toJSON()discord.js билдеры и инстансы компонентов

Сообщение распознаётся не по «наличию type», а по не-компонентному типу (0/19/20/…): это позволяет принимать и объект сообщения, и массив из одного сообщения (например, [await ctx.fetchReply()]). Достаётся и plain-контент.

Поглощение root-контейнера

Если корневой компонент один и это контейнер — он поглощается целиком (цвет, spoiler, дети). Иначе всё оборачивается в неявный контейнер, чтобы fluent-API продолжало работать.

ts
const builder = new V2Builder(message.components);  // тоже работает
const builder2 = parseComponents(ctx.message.components[0].components); // дети контейнера

Откуда появляется билдер при нажатии кнопки

Типичный полный цикл в discordx:

ts
import { Discord, Button } from "discordx";
import type { ButtonInteraction } from "discord.js";
import { V2Builder } from "discordjs-components-v2";

@Discord()
class News {
  @Button({ id: "news:like" })
  async like(interaction: ButtonInteraction) {
    const builder = V2Builder.parse(interaction.message);

    const btn = builder.find("news:like");
    if (btn?.component) (btn.component as { disabled?: boolean }).disabled = true;

    await builder.send(interaction); // update
  }
}
⚠️ Флаги при редактировании

Когда редактируете CV2-сообщение через discord.js напрямую, сохраняйте флаг IS_COMPONENTS_V2 (32 768), иначе Discord его отвергнет (UNION_TYPE_CHOICES). builder.send() делает это сам.
