Getting started

Установка и быстрый старт

Первый компонент V2 — меньше чем за минуту.

Установка

Либа не зависит от discord.js в рантайме, но нужны типы API:

bash
npm install discordjs-components-v2 discord-api-types

Peer-зависимости для полноценной интеграции:

  • TypeScript ≥ 5.0
  • discord.js ≥ 14.27 (для отправки и интеракций)
  • discord-api-types ≥ 0.38.8

Первый builder

V2Builder — декларативная сборка. Каждый метод возвращает this, поэтому всё можно чейнить. build() в конце валидирует дерево и возвращает готовый payload для отправки.

ts
import { V2Builder } from "discordjs-components-v2";

const payload = new V2Builder()
  .color(0xffaa00)
  .text("# 🎉 Розыгрыш")
  .field("Приз", "100 монет")
  .fields([
    { name: "Участников", value: "0" },
    { name: "До конца", value: "<t:1735689600:R>" },
  ])
  .buttons(
    { id: "join", label: "Участвовать", style: "Success", emoji: "🎟️" },
    { url: "https://example.com", label: "Правила" },
  )
  .selectMenu.string({
    customId: "category",
    placeholder: "Категория приза",
    options: [
      { label: "Игры", value: "games", emoji: "🎮" },
      { label: "Скины", value: "skins" },
    ],
  })
  .build(); // → { components, files?, flags: 32768 }

await interaction.reply(payload);

Что вернул build():

Поле Описание
componentsмассив из одного root-контейнера в формате API
flags32 768 (IS_COMPONENTS_V2) — обязательно для CV2
content?plain-текст над компонентами, если задан
files?вложения из .file() / .media()
ℹ️ Flag IS_COMPONENTS_V2

Без флага 32 768 Discord вернёт ошибку UNION_TYPE_CHOICES. Библиотека ставит его автоматически в build().

Отправка через send()

Вместо ручного раскидывания payload есть builder.send(target). Он сам выбирает способ ответа в зависимости от состояния интеракции:

Состояние targetЧто вызовется
интеракция, ещё не отвеченаinteraction.reply(...)
интеракция с replied/deferredinteraction.editReply(...)
любой target с followUpinteraction.followUp(...)
сообщение (msg.edit)message.edit(...)
ts
// эфемерный ответ первой командой
await builder.send(interaction, { ephemeral: true });

// отдельные доп. флаги
await builder.send(interaction, { extraFlags: 1 << 15 });

Полный пример с discordx

ts
import { Discord, Slash } from "discordx";
import type { CommandInteraction } from "discord.js";
import { V2Builder } from "discordjs-components-v2";

@Discord()
class News {
  @Slash({ name: "news", description: "Показать новость" })
  async news(interaction: CommandInteraction) {
    const builder = new V2Builder()
      .section({ title: "Обновление 2.2", content: "Что нового", thumbnailUrl: "https://example.com/2.2.png" })
      .text("Тут могла бы быть ваша реклама.")
      .separator("large")
      .buttons({ id: "news:like", label: "👍", style: "Primary" });

    await builder.send(interaction);
  }
}
