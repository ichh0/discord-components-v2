Editing

Редактирование

Точечные правки дерева компонентов: селекторы, кнопки, селекты, текст.

ComponentsEditor — цепочный редактор

editComponents(data) принимает то же, что и парсер (сообщение, сырые компоненты, билдеры…), но работает с глубокой копией — вход никогда не мутируется.

ts
import { editComponents } from "discordjs-components-v2";

const components = editComponents(await interaction.fetchReply())
  .disableButtons()              // выключить все кнопки
  .enableButtons("open")         // …кроме одной
  .removeButtons("rules")        // кнопку rules — удалить вообще
  .remove("pick")                // убрать любой компонент по customId
  .remove("textDisplay", 1)      // убрать 2-й текстовый блок по kind-индексу
  .setButtonLabel("join", "Голосовать")
  .replaceText("100 монет", "200 монет")
  .toJSON();

await interaction.editReply({ components, flags: 32768 });
ℹ️ Авто-чистка

После удалений пустые ActionRow удаляются, секция без текста или аксессуара — тоже (Discord такое не принимает).

Кнопки

ts
editComponents(msg)
  .setButtonLabel("join", "Голосовать")
  .setButtonStyle("join", 3)                // → Danger (убирает/ставит url и custom_id корректно)
  .setButtonEmoji("join", "👍")             // строка как в parseEmoji
  .setButtonEmoji("join", undefined)        // убрать эмодзи
  .setButtonUrl("docs", "https://…")        // превращает в Link-кнопку
  .renameCustomId("join", "leave")          // переименовать везде, кидает, если ничего не нашлось
  .disableButtons(["a", "b"])               // только перечисленные
  .setDisabled("join", false);              // включить конкретную

Селект-меню

SelectMenuMatchOptions = { type?, customIds? }; type — "string" | "user" | "role" | "channel" | "mentionable" (можно массив), customIds — строка или массив.

ts
editComponents(msg)
  .removeSelectMenus({ type: "string" })                    // убрать все строковые селекты
  .removeSelectMenus({ type: ["role", "user"], customIds: "filter" })
  .clearSelectValues({ type: "mentionable" })               // сбросить выбор (default_values / default)
  .getSelectMenus({ type: "user" })                         // массив raw-компонентов
  .findSelectMenu({ customIds: "pick" })                    // первый или null
  .setSelectPlaceholder("pick", "Выбери")
  .setSelectOptions("pick", [
    { label: "X", value: "x", emoji: ":fire:" },
    { label: "Y", value: "y", default: true },
  ])
  .setSelectMinMaxValues("pick", 1, 3)                      // undefined — убрать
  .setSelectDisabled({ type: "role" })
  .replaceSelectMenu({ customIds: "roles" }, { type: 2, style: 1, label: "Go", custom_id: "go" });

Текст

ts
editComponents(msg)
  .replaceText("0 участников", "1 участник")   // string или RegExp
  .replaceText(/\{\{__([A-Z_]+)\}\}/g, (m, key) => pages[key]); // replacer-функция тоже ок
  .getTexts();                                 // [string] — все TextDisplay'ы подряд
💡 Замена текста + шаблоны

Сентинелы вроде {{__CONTENT}} делают реплейс детерминированным и не зависящим от содержимого. Это основа готовых модулей шаблонов и пагинации — см. Шаблоны и пагинация и паттерн Пагинация вручную.

Поиск и извлечение информации

ts
builder.find("join");                     // ComponentRef | null — нода + путь + родитель
builder.findAll(ComponentType.TextDisplay);
builder.getTexts();                       // содержимое всех текстовых блоков

findComponents(rawArray, selector);       // standalone-версия

Все операции доступны и как standalone-функции над сырым массивом, и как методы V2Builder — единое ядро в edit/operations.

⚠️ Флаги при ручном editReply

Передавайте flags из полученного сообщения, либо используйте builder.send(ctx), который сам ставит IS_COMPONENTS_V2.
