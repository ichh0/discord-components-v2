V2Builder

Декларативная сборка сообщений Components V2: текст, layout, интерактив.

Содержание
  • Текст и контент
  • Layout-компоненты
  • Кнопки и селекты
  • Свойства контейнера
  • Сводная таблица

Текст и контент

У сообщения есть два «текстовых» уровня: plain-контент над компонентами и TextDisplay — markdown-блоки внутри контейнера. Контент задаётся методами ниже.

ts
new V2Builder()
  .content("Сообщение над компонентами")  // plain, вне контейнера
  .text("# Заголовок в TextDisplay")      // markdown-блок
  .field("Приз", "100 монет")             // "**Приз**\n100 монет"
  .field("Число", "7", true)              // inline: "**Число** 7"
  .fields([
    { name: "Участников", value: "0" },
    { name: "До конца", value: "<t:1735689600:R>" },
  ]);

.fields() рисует выровненную двухколоночную таблицу в ANSI-codeblock — идеально для «статов» с числами. Пустой массив просто ничего не добавляет.

Layout-компоненты

Section

Секция — это заголовок с контентом и обязательным «аксессуаром»: кнопкой или thumbnail.

ts
new V2Builder()
  .section({ title: "🏆 Топ-1", content: "Поздравляем!", button: { id: "top:claim", label: "Получить" } })
  .section({ title: "Картинка", thumbnailUrl: "https://example.com/img.png", thumbnailDescription: "подпись", spoiler: true })
  // thumbnailUrl + button одновременно — кинут ошибку

Разделители

ts
new V2Builder()
  .separator()                 // small, с линией
  .separator("large")          // большой отступ
  .separator("medium", false); // отступ без разделительной линии

Галереи и вложения

ts
new V2Builder()
  .gallery(["https://a.png", { url: "https://b.png", description: "подпись", spoiler: true }])
  .media(Buffer.from(...), "screenshot.png")   // attachment::// + галерея
  .mediaUrl("https://c.png", "одна картинка")
  .file(Buffer.from(...), "file.bin", true);   // File-компонент + files

Кнопки и селекты

Кнопки

Один ряд — до 5 кнопок. Три вида: с id, с url, со skuId.

ts
new V2Builder().buttons(
  { id: "join", label: "Войти", style: "Success", emoji: "🎟️" },
  { id: "dm", label: "В ЛС", style: "Secondary", disabled: true },
  { url: "https://example.com", label: "Сайт" },
  { emoji: "⭐", style: "Primary" },          // можно только эмодзи
);
// больше 5 кнопок в ряду → ошибка

style — строка: "Primary" | "Secondary" | "Success" | "Danger" | "Link" | "Premium".

Селект-меню

Каждый селект — отдельный ряд. Доступно через пространство имён selectMenu:

ts
new V2Builder()
  .selectMenu.string({ customId: "cat", placeholder: "Категория", options: [
    { label: "Игры", value: "games", emoji: "🎮", description: "...", default: true },
  ]})
  .selectMenu.user({ customId: "pick", placeholder: "Кто?" })
  .selectMenu.role({ customId: "role" })
  .selectMenu.mentionable({ customId: "mention" })
  .selectMenu.channel({ customId: "chan", channelTypes: [0] });

Общие опции: placeholder, minValues, maxValues, disabled. Эмодзи принимаются строкой: "👍", ":name:", "<:name:id>", "<a:name:id>".

Свойства контейнера

ts
new V2Builder()
  .color(0xffaa00)      // акцентная полоска слева
  .spoiler(true)        // спойлер-обёртка всего контейнера
  .setId(42);           // числовой id контейнера (для апи)

ℹ️ Редактирование прямо на билдере

Всё, что описано на странице «Редактирование», доступно и как методы билдера: disableButtons, setButtonLabel, replaceText, remove, renameCustomId и т.д. Посекционное управление — тоже: builder.all("section"), builder.sections.remove(1).
