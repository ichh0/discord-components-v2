Секции и layout-компоненты

Управление Section, Separator, TextDisplay, MediaGallery и ActionRow по индексам.

V2Builder и ComponentsEditor позволяют гибко управлять компонентами внутри контейнера по их индексу. Каждый тип индексируется отдельно — считаются только компоненты своего вида.

ℹ️ Что значит «индекс»

index — позиция среди детей того же типа (0-based), containerIndex — позиция в raw-массиве components контейнера.

Сводная таблица операций

Индексы считаются отдельно для каждого вида («kind»): sections, separators, textDisplay, actionRow, mediaGallery. Любой метод доступен в двух формах — generic-метод ядра и посекционный namespace (одинаковое поведение).

Тип (kind)Список / одинУдалить / заменить
Section .all("section") · .get("section", i) .remove("section", i) · .replace({ kind: "section", index: i }, r)
Separator .all("separator") · .get("separator", i) .remove("separator", i) · .replace({ kind: "separator", index: i }, r)
TextDisplay .all("textDisplay") · .get("textDisplay", i) .remove("textDisplay", i) · .replace({ kind: "textDisplay", index: i }, r)
MediaGallery .all("mediaGallery") · .get("mediaGallery", i) .remove("mediaGallery", i) · .replace({ kind: "mediaGallery", index: i }, r)
ActionRow .all("actionRow") · .get("actionRow", i) .remove("actionRow", i) · .replace({ kind: "actionRow", index: i }, r)
Namespace-шорткаты

Для каждого kind есть посекционный аксессор с тем же набором методов (all / get / set / remove / move) — удобно для точечных правок: builder.sections.remove(1), editor.textDisplays.set(2, "привет"), builder.separators.get(0).

remove/replace/move возвращают this — можно чейнить. set для textDisplay принимает обычную строку: builder.textDisplays.set(2, "новый текст").

Примеры

ts
const builder = V2Builder.parse(message);

// Сколько секций в компоненте?
const sections = builder.all("section"); // [{ index: 0, component, containerIndex: 2 }, ...]

// Удалить второй разделитель
builder.remove("separator", 1);
// то же самое:
builder.separators.remove(1);

// Убрать все разделители между секциями
while (builder.all("separator").length) builder.remove("separator", 0);

// Удалить один текстовый блок
builder.remove("textDisplay", 0);

// Заменить первую секцию целиком
builder.replace({ kind: "section", index: 0 }, {
  type: ComponentType.Section,
  components: [{ type: ComponentType.TextDisplay, content: "**Новый заголовок**\nНовый контент" }],
  accessory: { type: ComponentType.Thumbnail, media: { url: "https://example.com/img.png" } },
});

// Переместить последнюю секцию наверх
builder.move("section", 2, 0);

// Чейнинг: убрать одну секцию и переставить оставшиеся
builder.remove("section", 1).move("section", 0, 1);

await builder.send(interaction);

Через ComponentsEditor и standalone-функции

ts
editComponents(message)
  .remove("separator", 1)
  .remove("textDisplay", 0)
  .all("section");
ts
import { getAllByKind, removeByKind } from "discordjs-components-v2";
import { moveByKind } from "discordjs-components-v2/lib/advanced";

const seps = getAllByKind(container.components, "separator"); // [{ index, component, containerIndex }]
removeByKind(container.components, "separator", 1);
moveByKind(container.components, "separator", 2, 0);

Standalone-функции автоматом раскрывают корневой контейнер: их можно звать как на [...], так и на [container].

⚠️ Секции требуют аксессуар

Discord не принимает секцию без thumbnail/button. При удалении аксессуара секция удаляется целиком; замена/удаление по kind всегда оставляют дерево валидным.
